# Knowledge base

The retrieval experiments index four papers. They are copyrighted, so they are not in this repository. Put your own copies of the PDFs in this folder; any file name works, but the mental accounting paper's file name must contain "Mental Accounting" so the replication condition (R0) can find it.

1. Zeelenberg, M., & Pieters, R. (2007). A theory of regret regulation 1.0. *Journal of Consumer Psychology*, 17(1), 3–18.
2. Chua, H. F., Gonzalez, R., Taylor, S. F., Welsh, R. C., & Liberzon, I. (2009). Decision-related loss: Regret and disappointment. *NeuroImage*, 47(4), 2031–2040.
3. Chatterjee, S., Heath, T. B., & Min, J. (2009). The susceptibility of mental accounting principles to evaluation mode effects. *Journal of Behavioral Decision Making*, 22(2), 120–137. (Used file name: `Susceptibility of Mental Accounting Principles - Session3.pdf`.)
4. Kirmani, A., & Rao, A. R. (2000). No pain, no gain: A critical review of the literature on signaling unobservable product quality. *Journal of Marketing*, 64(2), 66–79. (Our copy was a scanned image with almost no extractable text.)

You only need the PDFs to rebuild the knowledge base from scratch. The cached embeddings and model responses in `results/llm_cache/` reproduce every reported number without them.
